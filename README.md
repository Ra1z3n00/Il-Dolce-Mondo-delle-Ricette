# 🍰 Il Dolce Mondo delle Ricette - Pasticceria Artigianale

Un'applicazione web vetrina e ricettario per una pasticceria artigianale, progettata con un layout moderno, fluido e completamente reattivo (*responsive*) per dispositivi mobile e desktop.

---

## 🚀 Demo Live

Puoi visualizzare il sito web live al seguente indirizzo:  
👉 **[https://Ra1z3n00.github.io/pasticceria/](https://Ra1z3n00.github.io/pasticceria/)**  

---

## ✨ Caratteristiche Principali

- **Griglia Prodotti Dinamica:** Schede con immagini e titoli per ogni dolce o ricetta.
- **Design Responsive:**
  - Layout adattivo in base al dispositivo (PC, Tablet, Smartphone).
  - Menu laterale di navigazione per categorie, che su dispositivi mobile si trasforma in un comodo **menu a comparsa (accordion)** usando elementi nativi HTML5 (`<details>` e `<summary>`).
- **Piattaforma Leggera:** Realizzato in HTML5 e CSS3 puro, privo di dipendenze esterne o librerie pesanti.

---

## 🛠️ Tecnologie Utilizzate

- **HTML5:** Struttura semantica dell'applicazione web.
- **CSS3:** 
  - Flexbox e CSS Grid per la gestione del layout.
  - Media Queries per la compatibilità mobile/tablet.
- **Git & GitHub Pages:** Per la gestione del controllo versione e il deployment automatico.
